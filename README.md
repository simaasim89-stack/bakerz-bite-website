# Bakerz Bite Website
Pages: index, menu, about, contact, gallery, merchandise, faq, feedback, sitemap.
Features: menu filter by category, live search, price sorting, quick-view modal, working cart (saved in browser), scroll and hover animations.
Products live in the `P` array at the top of `js/script.js` - edit one line to change a card.
Needs internet for Bootstrap, jQuery and Google Fonts (CDN). Open index.html to run.
Recent polish: fixed bakery location (North Nazimabad, Karachi, Pakistan; 24.86, 67.01), visitor counter in the top-right corner, footer navigation on every page, consistent palette and subtle animations. The visitor count uses a shared counter service when online and a local fallback otherwise.
